One-time Firebase setup. Your config is saved in your browser.

Setup (~3 minutes):
1. Go to console.firebase.google.com
2. Add project → name it → disable Analytics → Create
3. Click the </> Web icon → register app → copy the config values
4. Left sidebar → Build → Firestore Database → Create database → Start in test mode
5. Left sidebar → Build → Authentication → Get started → Email/Password → Enable → Save
