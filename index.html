🔍 Google Image Search Setup

Free — 100 searches/day. One-time setup takes ~5 minutes.
Your keys are saved in your browser only, never sent anywhere else.

Step 1 — Get API Key:
1. Go to console.cloud.google.com/apis/credentials
2. Click Create credentials → API key → copy it
3. Then go to Custom Search API → click Enable

Step 2 — Get Search Engine ID:
1. Go to programmablesearchengine.google.com
2. Name it anything, enable Search the entire web, click Create
3. Click your new engine → Customise → Copy the Search engine ID
